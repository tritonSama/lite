# Fluorescent: Game Maps IRL

Fluorescent is a general-purpose community task and service marketplace built with Flutter and Firebase, that is evolving into a persistent, game-like representation of the real automotive world.

It restores the ability for ordinary people to turn useful work into an opportunity to earn, while allowing the community to decide what work deserves funding.

## Getting Started

This project is a Flutter application using Firebase as its backend.

### Prerequisites

*   Flutter SDK (^3.8.0)
*   Firebase project setup with Firestore, Authentication, and Storage configured.

### Running the App

1.  Clone the repository.
2.  Run `flutter pub get` to install dependencies.
3.  Ensure your `firebase_options.dart`, `google-services.json`, and `GoogleService-Info.plist` are configured correctly for your Firebase project.
4.  Run `flutter run` to launch the app on your desired device or emulator.
